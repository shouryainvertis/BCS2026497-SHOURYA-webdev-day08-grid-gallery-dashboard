# NOVA SPACE — Creative Workspace & Product Studio

A modern and responsive creative workspace website built using HTML5, CSS3, and JavaScript.

NOVA SPACE is a digital showcase that brings together creative photography, featured projects, workspace statistics, and a curated product collection in a clean and modern interface.

## Project Overview

NOVA SPACE is a single-page responsive website designed with a modern lavender and white colour palette.

The project demonstrates the practical implementation of HTML structure, CSS layouts, responsive design, and JavaScript-based interactions.

All HTML, CSS, and JavaScript code is maintained in a single `index.html` file.

---

## Key Features

- Modern and responsive navigation bar.
- Attractive hero section with gradient styling.
- Creative photography gallery.
- Featured project showcase.
- Workspace overview dashboard.
- Statistics and activity cards.
- Product collection with 9 products.
- Product search functionality.
- Category-based product filtering.
- Light and dark theme toggle.
- Mobile navigation menu.
- Newsletter subscription demo.
- Back-to-top functionality.
- Responsive footer design.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Locate `index.html`.
4. Open it in any modern web browser.
5. Explore the website and its interactive features.

No additional installation is required.

## Responsive Design

The website is designed to work across different screen sizes:

- Desktop Computers
- Laptops
- Tablets
- Android Smartphones
- Other Mobile Devices

CSS media queries are used to adjust layouts for different screen widths.
